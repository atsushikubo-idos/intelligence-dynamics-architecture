# Architecture and epistemic boundaries

**The objective is difference-preserving interoperability**, not forced consensus. Participants have distinct reference frames; A→B and B→A need not carry equivalent meaning. The existing Reference v1.2 remains authoritative for CDP structures.

Data flow: source claims + rendition → CDP partial structural descriptions → automatic *candidate* assessments → explicitly unresolved ledger status → optional independent reviewer-attested findings → directional exchange summaries over time.

The model-assisted assessment entry point accepts a caller-supplied AI provider. Its output remains hypothetical and must be independently checked before any determinate state is recorded. This is deliberate: automation should surface possible losses, not erase uncertainty.

Observed exchange records support time-dependent analysis but do not establish a novel ontological relation trajectory. Unknown and unexpressed differences are still outside the detector's observational reach. Changing this would require additional instrumentation and experiments, not stronger labels.
